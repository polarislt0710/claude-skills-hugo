# Pixel Agents Assets

Source: https://github.com/pablodelucca/pixel-agents

License: MIT. Copyright (c) 2026 Pablo De Lucca.

The office assets copied into this directory come from `webview-ui/public/assets/` in the Pixel Agents project. The upstream README notes that the character sprites are based on JIK-A-4's Metro City free top-down character pack: https://jik-a-4.itch.io/metrocity-free-topdown-character-pack

The current Swarm Dashboard renderer draws procedural pixel agents and an office scene in canvas, so these assets are staged for future scene/sprite expansion.
