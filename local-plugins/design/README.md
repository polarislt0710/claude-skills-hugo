# design

Professional UI design rules split into 4 categories. Each sub-skill contains 5 concrete, opinionated rules with WCAG-aligned defaults.

| Skill | Rules covered |
|---|---|
| `typography` | Type scale, weight, measure, paragraph spacing, contrast |
| `color` | Palette systems, contrast checking, semantic usage, hierarchy, surfaces |
| `layout` | Grids, spacing scales, alignment, proximity, visual weight |
| `components` | Buttons, forms, cards, icons, motion |

Use individually for focused review (e.g., `design:typography` to audit type only) or apply all four for a full UI design pass.
