# marketing

Marketing skills split by discipline. Each sub-skill answers a specific marketer's question.

| Skill | Question |
|---|---|
| `copywriting` | "What words should I use?" — AIDA, PAS, FAB frameworks |
| `content-templates` | "What should I write/post?" — landing pages, email, social media |
| `growth-strategies` | "How do I acquire users?" — B2B SaaS + Consumer playbooks |
| `conversion` | "Why aren't people clicking?" — landing page audit + copywriting rules |
| `seo` | "How do I rank?" — keyword strategy + content briefs |
