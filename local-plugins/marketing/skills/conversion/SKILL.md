# Conversion Optimization

Conversion is the difference between traffic and revenue. Most landing pages leak at predictable points — fix those FIRST.

## Landing page audit checklist

Run this BEFORE more advanced experiments:

- [ ] **Headline answers "what is this + for who"** in <10 words
- [ ] **CTA is above the fold** on mobile AND desktop
- [ ] **Social proof is near the CTA** (eyes flick proof → CTA)
- [ ] **Mobile-optimized** (the 60–80% of traffic depending on niche)
- [ ] **Page loads in < 2 seconds** (Lighthouse, real device)
- [ ] **Single focus** — one conversion goal (NOT signup + demo + download + newsletter)
- [ ] **Trust signals** visible: logos, numbers ("10,000 teams"), one named testimonial
- [ ] **Friction audit**: number of form fields = 1, 2, or 3 max for top-of-funnel

## Copywriting rules (conversion-specific)

1. **Specificity beats vague.** "Reduce onboarding from 3 days to 30 minutes" >>> "Faster onboarding"
2. **Address the reader as "you"** — never "the user", "customers".
3. **Benefits over features** — always lead with what it MEANS for them.
4. **Short sentences. Short paragraphs.** Mobile readers skim.
5. **Every word earns its place.** Cut adverbs, cut "really", "very", "just".
6. **Concrete proof > abstract claims.** Numbers, names, screenshots > adjectives.

## What to test (in priority order)

1. **Headline / hero value prop** — biggest lever
2. **CTA copy + button color** — second biggest
3. **Social proof placement / specificity**
4. **Form field count**
5. **Hero image / video**

Stop testing button color until #1 and #2 are nailed.

## Common conversion killers

- Generic stock photos (smiling diverse team in bright office)
- Vague headlines ("Empower your team")
- Multiple primary CTAs competing
- Long forms before value is shown
- Pop-ups before user has read anything
- Auto-playing video with sound
- "Learn more" CTA (says nothing about reward)
