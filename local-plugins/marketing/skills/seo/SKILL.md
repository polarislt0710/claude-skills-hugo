# SEO Content Framework

SEO that converts in 2026 = answer search intent better than the top result, with original credibility.

## Keyword strategy by funnel stage

| Stage | Pattern | Examples |
|---|---|---|
| **Top of funnel (TOFU)** | Problem + what / why / how | `"why is my CSS broken"`, `"how to debug API 500"` |
| **Middle of funnel (MOFU)** | Best [solution category] for [use case] | `"best monitoring tool for django"`, `"alternatives to splunk"` |
| **Bottom of funnel (BOFU)** | [Product] vs [Competitor], [Product] review, [Product] pricing | `"datadog vs new relic"`, `"sentry pricing"` |

Match content type to stage:
- TOFU → guide / tutorial / explainer (educational, link-magnet)
- MOFU → comparison / listicle / round-up (decision support)
- BOFU → product page / case study / pricing (conversion)

## Content brief template

```
TARGET KEYWORD:    [primary kw + 2-3 supporting]
SEARCH INTENT:     [informational / commercial / transactional / navigational]
TARGET READER:     [persona — what role + what problem]
CONTENT ANGLE:     [why YOUR take is different — original data, deeper reporting, contrarian]
WORD COUNT:        [match top 3 SERP results, ±20%]

KEY SECTIONS:
  1. [H2]            [what to cover, why]
  2. [H2]            ...
  3. [H2]            ...

INTERNAL LINKS:    [3-5 related pieces in your content cluster]
EXTERNAL LINKS:    [authoritative sources to cite — NOT competitors]
SCHEMA:            [Article, FAQPage, HowTo — pick correct type]
CTA:               [next step matching funnel stage]
```

## What actually moves rankings (in order)

1. **Match search intent** — the #1 result solves what the searcher actually wants.
2. **Topical authority** — cluster of related content > one isolated post.
3. **First-hand experience / original data** — "I tested 12 of these" > paraphrasing other articles.
4. **Internal linking** — connect related content with descriptive anchor text.
5. **Backlinks** — earned through real value, not bought / spammed.
6. **Technical SEO** — fast, indexable, structured data — table stakes, not differentiator.
7. **Word count / keyword density** — minor effects, last priority.

## Avoid

- Keyword stuffing (Google detects, penalizes)
- Spinning / paraphrasing competitor content
- Thin content masquerading as comprehensive
- Targeting keywords with no commercial intent if the goal is revenue
