# media-tools

Programmatic media generation — 2 skills.

| Skill | Purpose |
|---|---|
| `cantonese-ai` | Cantonese.ai TTS / voice clone / Jyutping wrapper with bundled `scripts/` (needs `CANTONESE_AI_API_KEY`) |
| `remotion` | React-based programmatic video: core API patterns + production rules (merged from remotion-video + remotion-best-practices) |

Distinct from the `ai-prompts` plugin: `ai-prompts` writes *prompts* for external generators (Midjourney, Veo, Kling); `media-tools` *generates media directly* with code.

Upstream dev workspace for cantonese-ai: `~/cantonese-ai-skill/` (test .wav files live there, not bundled here).
